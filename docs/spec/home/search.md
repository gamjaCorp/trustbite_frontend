## 1. 입력 분류별 동작

타이핑만으로는 지도가 움직이지 않는다. 지도 이동·가게 클로즈업은 항상 **사용자 확정(클릭 또는 Enter)** 으로만 일어난다.

### 케이스 A — 지역·역·관광지

> 예: "강남구", "역삼동", "강남역", "남산타워"

- dropdown이 열리지 않는다.
- 대신 input 바로 아래에 한 줄 힌트가 표시된다.
  ```
  ↵  강남구로 이동
  ```
- Enter를 누르면 지도가 해당 위치로 이동하고, 그 영역의 맛집 목록이 자동으로 불러와진다.
- 지역 확정 후 검색창은 **빈칸으로 비워진다**.

### 케이스 B — 가게·음식 키워드

> 예: "스시오마카세", "광화문국밥", "파스타"

- input 아래에 **자동완성 dropdown**이 열린다.
- 각 항목에는 썸네일(사진이 없으면 카테고리 아이콘) / 가게명 / 주소 / 카테고리가 표시된다.
- 드롭다운에는 음식점·카페 카테고리 가게만 노출된다. 약국·편의점·마트 등 비음식 장소는 제외된다.
- 항목을 클릭하거나 ↑↓ 키로 이동 후 Enter를 누르면, 그 가게로 지도가 클로즈업되고 결과 리스트에 해당 가게 1개만 표시된다 (focus 모드 진입).
- Enter를 하이라이트 없이 누르면 첫 번째 항목이 자동 확정된다.

### 케이스 C — 결과 없음

> 예: 오타, 의미 불명 입력

- dropdown도, 힌트도 표시되지 않는다.
- Enter를 눌러도 아무 동작이 없다.

## 2. 상세 인터랙션

### 2-1. 키보드·마우스 동작 전체

| 액션 | 결과 |
|---|---|
| 타이핑 (debounce 500ms) | 백엔드 suggest 호출. 지도는 그대로 |
| dropdown 항목 클릭 | 가게 클로즈업 (focus 모드 진입) |
| ↑ ↓ 키 | dropdown 항목 하이라이트 이동 |
| Enter (area 모드) | 지도를 `area.center`로 이동. 검색창 비움 |
| Enter (keyword 모드, 하이라이트 있음) | 그 항목 확정 → 클로즈업 |
| Enter (keyword 모드, 하이라이트 없음) | 1번째 항목 자동 확정 → 클로즈업 |
| ESC | dropdown 닫기 + focus 모드 해제 |
| Clear (X) 버튼 | 입력 비움, focus 모드 해제, viewport 모드 복귀 |

### 2-2. Focus 모드 (가게 확정 후 상태)

keyword 항목이 확정되면 `focusedPlace` 상태 진입:

- 결과 리스트: 그 가게 1행만 표시
- 지도: 핀 1개, 클로즈업 (zoom level 2 수준)
- viewport 검색 비활성 — 지도를 드래그·줌해도 결과 유지
- 해제 조건: 입력 비움 / ESC / Clear(X) 버튼 / 다른 항목 선택 / 검색어 수정(타이핑) / 헤더 로고 클릭

## 3. 미정·논의 필요

- **빈 결과 UX** — "결과 없음" 1줄 노출 vs dropdown 자체 닫음
- **Focus 모드 해제 시점** — 지도 드래그로도 풀지 (현 안: 풀지 않음, 사용자 명시 액션에서만)
