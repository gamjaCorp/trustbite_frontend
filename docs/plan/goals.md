## 4주 후 (6/6) — 1차 MVP 완료 정의

아래 항목이 **모두** 충족되어야 1차 MVP 완료다.

| 항목                                  | 기준                                                               |
| ------------------------------------- | ------------------------------------------------------------------ |
| PRD 1차 MVP 9개 화면                  | 브라우저에서 모두 렌더링, 크래시 없음                              |
| 핵심 루프 완주                        | 탐색 → 맛집 상세 → 리뷰 작성 → 신뢰도 결과 → 등급 안내 → `/profile` |
| 탐색 탭                               | 검색·지역·정렬·카테고리·상황 필터 동작 + 카카오 지도 핀/시트       |
| 데이터 레이어                         | `src/data/mock-*` 파일 0개, 모든 화면이 실 백엔드 API 위에서 (`api/` + `hooks/`)  |
| 인증 가드                             | 미들웨어 통합, 비로그인 → `/login?next=` 리다이렉트 일관           |
| 에러 화면                             | `not-found.tsx`, `error.tsx`, `/restaurant/[id]/error.tsx`         |
| 디자인 시스템                         | 시맨틱 타이포(`text-headline/title/body/label/caption-*`) 사용률 ≥ 90%, `common/` 제거, hex 위반 0 |
| 반응형                                | 375 (모바일) · 768 (태블릿) · 1280 (데스크톱) 레이아웃 정상       |
| 빌드                                  | `pnpm build` 에러 없음                                             |
| 스테이징 배포                         | Vercel preview URL 접근 가능, 내부 테스터 3~5명 피드백 시작        |

### 4주 안에 명시적으로 안 들어가는 것

- 위치 인증 (Geolocation API)
- trustScore Decay 자동 적용
- AI 취향 요약 (Anthropic API)
- 도움됐어요 커뮤니티 평판
- ELO 상대평가
- 팔로우 / 타임라인 / 포인트 시스템
- 뱃지 Lv.3~6 (1차 MVP는 Lv.1~2 범위)
- 방문 횟수 캐러셀
- **PWA** (manifest, service worker, 설치 프롬프트)
- **테스트 코드 작성** (인프라는 유지)
