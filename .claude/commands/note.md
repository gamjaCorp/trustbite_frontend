description: 이번 task의 질문·답변을 docs/note.md에 정리해 기록 — now 인자 시 직전 한 쌍만
---

`$ARGUMENTS`의 첫 토큰이 `now`이면 아래 `## now 모드`를 따른다. 그 외에는 `## 기본 모드`를 따른다.
승인 대기 없이 바로 기록한다.

## 기본 모드

이번 대화에서 **현재 task**에 해당하는 사용자 질문 + Claude 답변 쌍을 전부 대상으로 한다.

## now 모드

`## 3단계` 이전 내용은 무시하고, **직전 사용자 질문 + 그에 대한 답변 한 쌍만** 대상으로 한다.

## 1단계 — 범위 확정

대화 컨텍스트에서 대상 범위(기본 모드면 현재 task 전체, now 모드면 직전 한 쌍)에 속하는 질문·답변을 추출한다.

추출 결과가 비어 있으면 `"기록할 Q&A가 없습니다."`를 출력하고 종료한다.

## 2단계 — 정리

각 질문·답변 쌍을 아래 형식으로 재작성한다. 원문을 그대로 복붙하지 않는다 — 결론 먼저, 근거와 관련 파일 경로를 포함해 나중에 맥락 없이 읽어도 이해되게 압축한다.

```
**Q.** {한 줄로 압축한 질문}

**A.** {결론 → 근거 → 관련 파일 경로}

**배운 점** — {선택. 코드·커밋이 스스로 말해주지 못하는 것만}
```

날짜는 세션 컨텍스트의 `currentDate`를 쓴다 (`date` 등 셸 호출 불필요).

## 3단계 — 기록

`docs/note.md`를 확인한다.

- 파일이 없으면 `# Note` 제목 한 줄과 함께 새로 만들고, 그 아래 `## {날짜} — {task 한 줄 요약}` 섹션을 추가한 뒤 정리된 Q&A 블록을 넣는다.
- 파일이 있고 **마지막 섹션의 제목이 같은 날짜·같은 task**면 새 섹션을 만들지 않고 그 섹션 끝에 Q&A 블록만 이어 붙인다.
- 그 외의 경우 파일 맨 아래에 새 `## {날짜} — {task 한 줄 요약}` 섹션을 추가하고 그 안에 Q&A 블록을 넣는다.

항상 **append만** 한다 — 기존 섹션의 내용을 삭제하거나 재작성하지 않는다.

## 4단계 — 보고

아래 형식으로 짧게 보고한다.

```
📝 note.md 기록 완료 — "{섹션 제목}"에 Q&A N건 추가
```

## 가드레일

- `docs/note.md` 외 어떤 파일도 수정하지 않는다 (`week-*.md`, `week-*-issues.md`, 소스 코드 포함).
- git 커밋, 패키지 설치, 다른 슬래시 커맨드 호출 금지.
- 기존 섹션 삭제·재작성 금지 — 항상 append.
